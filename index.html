Automatic backup

The app backs up the database every 3 hours and shortly after it starts, to two places:

1. This PC: (protects against corruption, not against a dead disk)

2. Cloud folder: pick a folder that syncs to the cloud (Google Drive for desktop, OneDrive or Dropbox). This is what protects you if the SSD fails.

Last backup:

How to restore after a failure
  1. Install the app on the new/repaired PC and open it once, then close it.
  2. Copy the newest backup file (shop-DATE.db) from the cloud folder into C:\Users\<name>\AppData\Roaming\Garments POS\
  3. Delete any old shop.db, shop.db-wal, shop.db-shm there, then rename the copied file to shop.db. Open the app.
